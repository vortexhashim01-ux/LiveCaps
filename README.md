# 🚀PROJECT OVERVIEW

Traditional human detection systems primarily identify a person using rectangular bounding boxes. This project aims to provide a more detailed understanding of human movements through real-time landmark detection and tracking.

Using computer vision technologies, the application detects body joints, hand landmarks, and facial landmarks, enabling more advanced human movement analysis.

# ✨ Key Features

1. Full Body Pose Tracking

Real-time human pose estimation.

Detection of body joints and landmarks.

Skeleton visualization using connected landmarks.

Tracking of body movements.

2. Hand Tracking

Detection of hand landmarks.

Finger position tracking.

Recognition of hand gestures.

Real-time hand movement visualization.

3. Face Tracking

Facial landmark detection.

Face position tracking.

Head orientation estimation.

Real-time facial landmark visualization.

4. Advanced Movement Detection

Human movement recognition.

Joint angle calculations.

Gesture recognition.

Movement analysis and tracking.
